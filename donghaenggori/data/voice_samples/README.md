# 통화 표본 — STT 개선용

`VOICE_KEEP_SAMPLES=1` 일 때만 쌓인다. **기본은 꺼져 있다.**

```
20260819-213045-123456.wav   통화 녹음 원본 (8kHz PCM)
20260819-213045-123456.txt   STT 가 받아적은 결과 — **정답이 아니다**
```

## .txt 는 초안이다

STT 출력을 그대로 학습 라벨로 쓰면 모델이 자기 실수를 정답이라고 배운다.
사람이 음성을 들으며 고쳐야 라벨이 된다. 고칠 때 지킬 것:

- **들린 대로 적는다.** "가야겄어" 를 "가야겠어" 로 고치지 않는다 —
  방언을 표준어로 바꾸면 방언을 못 배운다.
- 병원명·지역명은 정확히. 여기가 제일 많이 틀리는 자리다.
- 알아들을 수 없으면 그 파일은 버린다. 추측해서 적으면 잡음이 된다.

## 왜 모으나

STT 를 고치려면 무엇을 틀리는지 재야 하는데, 전사 직후 지우면 하루를 써도
한 건도 안 남는다. 모델을 바꿔도 좋아졌는지 잴 수가 없다.

수백 건이 모이면 (1) 평가셋으로 모델을 비교하고 (2) 파인튜닝을 시도한다.
둘 다 지금은 데이터가 없어 못 한다.

## 개인정보

어르신의 목소리와 건강 이야기다. **저장소에 커밋하지 않는다**(.gitignore).

켜기 전 전제 둘은 코드에 넣었다 — 문서로만 두면 지켜지지 않는다.

- **녹음 고지**: `VOICE_KEEP_SAMPLES` 를 켜면 첫 안내에 "통화 내용은 상담
  품질을 높이기 위해 녹음되어 보관됩니다." 가 자동으로 붙는다. 등록·미등록
  발신자 **양쪽 경로 모두**에 붙는다(재이용자가 오히려 많이 쌓인다).
  끄면 문장도 같이 사라진다 — 안내와 실제 동작이 어긋날 수 없게 묶어 두었다.
  문구는 `CLAWOPS_RECORDING_NOTICE` 로 바꾼다.
- **보관 기간**: 기본 30일. `VOICE_SAMPLE_RETENTION_DAYS` 로 바꾸고,
  새 표본을 쌓을 때 지난 것을 함께 지운다(크론에 기대지 않는다).
  0 이하로 두면 안 지우지만, 그건 기관이 별도 보관 규정을 가질 때만이다.

라벨을 고쳐 학습셋으로 옮긴 뒤에는 원본을 남겨 둘 이유가 없다. 옮겼으면
지운다.
