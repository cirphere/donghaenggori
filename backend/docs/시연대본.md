`docs/발표구성.md` 의 앞단 3문답.

장면 하나만 기억하고 나가고, 그 후보가 장면 2다.

> ⚠️ **PR #55(팀원, 병원 상태 정책)가 머지되면 장면 1의 대사가 바뀐다.**

### 장면 2 · 확정이 막힌다 — 하이라이트 (대사 1:40 / 목표 2:30)

> 다음 통화입니다.
>
> `[화면] 새 접수 → "내일 아니고 모레 3시에 정형외과 가야 해"`

> 어르신이 말을 고치셨습니다. "내일 아니고 모레."
> 날짜는 **모레**로 잡혔고, 근거에 이렇게 남습니다 —
> "앞선 표현을 정정했으므로 마지막에 말한 것을 최종 의도로 봄".
>
> 그런데 시각이 비어 있습니다. "3시"라고 하셨는데요.
> 근거를 보시면 — "오전·오후를 말하지 않아 확정할 수 없음".
>
> **저희가 고르지 않았습니다.** 반반의 확률로 맞히면 어르신은 반나절을
> 헛걸음하십니다. 없는 것보다 틀린 것이 나쁩니다.

> 이제 확정을 눌러보겠습니다.
>
> `[화면] 확정 클릭 → 팝업`

> **막혔습니다.**
>
> "먼저 확인할 내용 1건 — 방문 시각. 어르신 말씀: 3시."
> 그리고 되물을 질문이 같이 떠 있습니다.
> **"말씀하신 3시, 오전인가요 오후인가요?"**
>
> 이 화면을 띄운 채로 어르신께 전화를 걸어 그대로 물어보고,
> 답을 바로 여기 적으면 됩니다.
>
> `[화면] 15:00 입력 → 확인 완료로 저장`

> 막고 있던 항목이 사라졌고, 버튼이 바뀌었습니다.
> 아까는 빨간 **"이대로 접수"**였는데 지금은 **"확정"**입니다.
>
> `[화면] 확정 클릭 → 감사 로그 탭`

> 그리고 남습니다. **누가, 언제, 무엇을 확정했는지.**
> 통화로 확인한 것도 따로 남습니다 — "항목확인, time=15:00".
>
> 확인을 안 하고 넘어갈 수도 있습니다. 어르신이 전화를 끊어버리는 일이
> 실제로 있으니까요. 다만 그때는 감사 로그에 **"미확인 확정"**으로 남습니다.
> 나중에 문제가 생기면 누가 무엇을 확인하지 않았는지 답할 수 있어야 합니다.

### 장면 3 · 긴급 — AI 가 판정하지 않는다 (대사 0:49 / 목표 1:30)

> `[화면] 새 접수 → "가슴이 답답하고 숨이 차"`

> **접수카드가 만들어지지 않았습니다.**
>
> 대신 이 안내가 뜹니다 — "긴급 신호 감지. 접수카드 생성을 중단하고 즉시
> 담당자 연결로 전환합니다. **동행고리 AI 는 응급 여부를 판단하지 않습니다.**"
>
> 저희는 의료 판단을 하지 않습니다. 응급인지 아닌지를 AI 가 정하는 순간
> 그건 다른 서비스가 됩니다. 저희가 하는 건 **놓치지 않고 사람에게 넘기는
> 것**까지입니다.
>
> 전화에서는 실제로 담당자에게 연결을 시도합니다. 그리고 **담당자가 못 받은
> 경우가 제일 위험합니다** — 어르신은 안내를 듣고 끊으시는데 아무도 그 사실을
> 모르면 다시 거는 사람이 없습니다. 그래서 연결 결과가 목록에 그대로 남습니다.
>
> `[화면] 목록의 "전환 응답없음" 배지`

### 장면 4 · 미등록 번호 (대사 0:53 / 목표 1:00)

> 등록되지 않은 번호로 걸려온 경우입니다.
>
> `[전화] 미등록 번호로 발신 → 성함·읍면동 질문에 답 → "병원 좀 가야 해"`

> 대상자가 "신규 대상자(미등록 번호)"입니다. 이력이 없으니 병원도 날짜도
> 잡히지 않았고요.
>
> 그래도 **접수는 됩니다.** 전화를 끊게 하지 않습니다.
> 성함과 읍면동을 여쭤보고, 들은 말을 그대로 남깁니다 —
> **확정하지는 않습니다.** 8kHz 전화 음질에서 받아 적은 이름을 확정으로 띄우면
> 복지사가 어르신을 그대로 잘못 부르게 됩니다.
>
> `[화면] 확정 클릭 → 3건이 막힌 팝업`

> 대상자, 병원, 방문일 — 세 가지를 확인해야 확정됩니다.
> 대상자 칸에는 통화에서 들은 성함이 이미 들어와 있어서,
> "성함이 어떻게 되세요"가 아니라 **"김말자 님 맞으실까요"**로 물을 수 있습니다.

> ⚠️ **이 장면은 반드시 전화로 한다.** 텍스트로 넣으면 성함을 물어보는 2턴이
> 없어서 대상자 칸이 빈칸으로 뜬다 — 위 마지막 문장이 성립하지 않는다.

### 장면 5 · 사후기록이 다음 접수를 좋게 만든다 (대사 0:39 / 목표 1:00)

> 동행이 끝나면 매니저가 메모를 남깁니다.
>
> `[화면] 사후기록 탭 → "무릎 주사 맞았고 다음 진료 2주 뒤, 약국 들렀어요.`
> `        계단 힘들어하셨습니다." → 기록 초안 만들기`

> AI 가 초안을 만들었습니다. 진료 내용, 다음 진료, 약국, 주의사항으로 나눠서요.
> "2주 뒤"는 **확정하지 않고** 일정 재확인 항목으로 빼두었습니다.
>
> **그런데 이건 제안입니다.** 승인을 눌러야 어르신 프로필에 반영됩니다.
> AI 가 케어 프로필을 자동으로 바꾸지 않습니다.
>
> `[화면] 승인 클릭`

> 이제 이 어르신이 다음에 전화하시면, 장면 1에서 보신 것처럼
> 병원 후보가 더 정확해집니다. 이력이 쌓였으니까요.

## 시간 배분 점검

대사 글자수를 세어 **분당 320자**(한국어 발표 속도)로 환산한 값이다.

| | 대사 | 목표 | 조작·정적에 남는 시간 |
|---|---|---|---|
| 소개 3장 | 0:47 | 2:00 | 1:13 |
| 장면 1 | 1:01 | 2:00 | 0:59 |
| **장면 2** | **1:40** | **2:30** | **0:50** |
| 장면 3 | 0:49 | 1:30 | 0:41 |
| 장면 4 | 0:53 | 1:00 | **0:07** ⚠ |
| 장면 5 | 0:39 | 1:00 | 0:21 |
| AI 기술 3장 | 1:29 | 2:00 | 0:31 |
| **합계** | **7:22** | **12:00** | **4:38** |

**말이 전체의 61% 다.** 남는 4분 38초로 전화 연결·화면 전환·클릭·정적을 전부
감당해야 한다. 넉넉하지 않다.

### 위험한 곳 둘

**장면 4 — 여유 7초.** 미등록 번호로 전화를 또 걸어야 하는데 대사만으로 목표를
거의 다 쓴다. **여기가 제일 먼저 터진다.**
→ 전화 대신 텍스트 입력으로 바꾸고, 마지막 문장("김말자 님 맞으실까요")을 뺀다.
   그러면 대사가 0:40 으로 줄고 조작도 5초면 끝난다.

**장면 1 — 실제 전화가 30~60초를 먹는다.** 여유 59초를 통화 하나가 다 쓴다.
안내 멘트를 듣는 동안 말을 얹어 시간을 겹쳐 써야 한다:
→ 발신 직후 "지금 안내 멘트가 나가고 있습니다. 어르신은 앱을 깔지도,
   챗봇과 대화하지도 않습니다" 를 통화 중에 말한다.

### 리허설에서 잴 것

스크립트(`demo_scenario`)는 1초면 끝난다 — **시간을 재주지 않는다.**
반드시 대본을 소리 내어 읽으며 실제로 화면을 조작해서 재야 한다.

장면별로 스톱워치를 끊고, 목표를 넘긴 장면이 있으면 **대사를 줄이지 말고
장면 4 를 텍스트 입력으로 바꾸는 것부터** 한다. 대사는 이미 최소한이다.

## 운영 메모

**장면 1의 실제 전화가 이 시연의 최대 무기이자 최대 위험이다.**
"실제 동작 여부"를 증명하는 유일한 장면인데, 회선·터널·STT 중 하나만 어긋나도
시작부터 막힌다. 반드시 대체 경로를 준비한다.

| 순위 | 방법 |
|---|---|
| 1 | 실제 전화 발신 |
| 2 | 미리 녹음해 둔 음성 파일 업로드 (`음성 파일` 버튼) |
| 3 | 발화 텍스트 직접 입력 (`시연 발화 모음` 버튼) |

전환할 때 사과하지 않는다 — "녹음해 둔 통화로 이어가겠습니다" 한 마디면 된다.

### 시작 전 점검

```bash
docker compose ps                     # 세 컨테이너 healthy
docker compose logs app | grep "전화 설정"    # 안내음성·녹음상한 확인
docker compose logs app | grep "AI 배치"      # 외부 LLM 미사용 확인
```

예열은 기동과 함께 자동으로 돈다(`WARMUP_ON_START=1`). 로그에 "예열 완료"가
뜬 뒤에 시작한다 — **첫 기동이면 1분 가까이 걸린다.**

### 데이터 초기화 — 순서가 있다

초기화는 **관리자만** 할 수 있고, 세션을 전부 지운다.

```bash
# 1) 관리자로 로그인 → 초기화
# 2) 다시 사회복지사로 로그인       ← 1)에서 받은 토큰은 죽는다
# 3) 장면 1을 먼저 돌려 이력을 만든다 ← 안 하면 장면 5가 참조할 게 없다
```

리허설 스크립트로 한 번에 확인하려면:

```bash
docker compose exec \
  -e DEMO_SW_ID=U001    -e DEMO_SW_PASSWORD='...' \
  -e DEMO_MGR_ID=U002   -e DEMO_MGR_PASSWORD='...' \
  -e DEMO_ADMIN_ID=U003 -e DEMO_ADMIN_PASSWORD='...' \
  app python -m tests.demo_scenario --full
```

**17/17 이 나와야 한다.** 호스트에서 `export` 한 값은 컨테이너로 넘어가지
않으므로 `-e` 로 넘겨야 한다.
